# Aircraft Data Collector

Консольное приложение для получения, фильтрации и сохранения информации о самолётах в воздушном пространстве выбранных стран.

## Возможности

- Получение координат страны через **Nominatim API**
- Получение данных о самолётах через **OpenSky API**
- Преобразование данных в объекты класса `Aeroplane`
- Сохранение информации о самолётах в **JSON-файл**
- Фильтрация самолётов по стране регистрации
- Получение **топ N** самолётов по высоте
- Взаимодействие с пользователем через консоль

## Стек технологий

- Python
- requests
- pytest
